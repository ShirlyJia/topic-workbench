# 基模-落地牵引项目管理

[打开画板](https://shirlyjia.github.io/topic-workbench/)

| 分支 | 用途 |
| --- | --- |
| `main` | 工作台前端。GitHub Pages 从仓库根目录发布。 |
| `topic-board-data` | 旧版公开画板的历史。 |
| `topic-workbench-source` | 带虚构数据和测试的开发示例，独立于线上画板。 |

工作台通过公司飞书账号登录。管理员编辑画板和会议记录，其他成员可以查看和留言。画板、会议和留言由工作台服务保存，页首显示最近一次画板同步时间。

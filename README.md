# 基模-落地牵引项目管理

[打开画板](https://shirlyjia.github.io/topic-workbench/)

| 分支 | 用途 |
| --- | --- |
| `main` | 当前网站的 HTML、CSS、JavaScript 和发布资料。GitHub Pages 从仓库根目录发布。 |
| `topic-board-data` | 线上画板的 `live-board.json` 和版本历史。Mac 自动同步只更新这个分支。 |
| `topic-workbench-source` | 带虚构数据和测试的开发示例，独立于线上画板。 |

访问者打开画板会读取线上版本，可在页首查看最近一次成功同步的北京时间。已连接自动同步的 Mac 保存修改后会交给本机后台发布。飞书资料仍按原文档权限访问。
